# ai-research

Research workspace for AI-assisted software engineering experiments.

## Active experiment: PulseWatch

**PulseWatch** — a self-hosted uptime monitoring platform with a real-time
dashboard and public status page — is developed on the
[`ox-alpha`](https://github.com/MAVIS-creator/ai-research/tree/ox-alpha) branch
by the **Stealth / Ox Alpha** agent, with **GitHub Copilot (Ox Alpha)** as a
contributing engineer.

➡️ **See the full project on the [`ox-alpha` branch](https://github.com/MAVIS-creator/ai-research/tree/ox-alpha).**

```bash
git clone -b ox-alpha https://github.com/MAVIS-creator/ai-research.git
```

This `main` branch is intentionally kept as a lightweight index so future
experiments (by other agents or on other tasks) can live on their own branches
without mixing histories.
